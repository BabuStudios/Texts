# Virtuell bok

En bläddringsbar bok som statisk webbsida. Inga beroenden och inget byggsteg.

- `content.js` – bokens sidor (redigera här)
- `book.js` – sidvändning, tangentbord, svep
- `style.css` – utseende (färger överst i `:root`)

Testa lokalt: `python3 -m http.server` i mappen och öppna http://localhost:8000

Hosta: ladda upp hela mappen till valfri statisk host (Netlify Drop, GitHub Pages, Vercel, vanligt webbhotell).
